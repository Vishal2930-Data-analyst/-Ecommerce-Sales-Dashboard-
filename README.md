# 🛒 Ecommerce Sales Dashboard 📊

## 🚀 Project Overview

This project is an interactive **Power BI Dashboard** designed to analyze and visualize Ecommerce sales data. It provides valuable business insights related to sales performance, profit trends, product demand, regional growth, and shipping efficiency.

The dashboard helps decision-makers track KPIs and identify growth opportunities using data-driven insights.

---

## 🎯 Key Features

✅ Total Sales Analysis  
✅ Total Profit Tracking  
✅ Quantity Sold Overview  
✅ Profit Margin Monitoring  
✅ Sales by Category  
✅ Top 5 Best Selling Products  
✅ Bottom 5 Low Performing Products  
✅ Sales by Region  
✅ Sales by Shipping Type  
✅ Top 5 States by Sales  
✅ Interactive Filters & Slicers
